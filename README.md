# 量化交易系统

**版本**: 1.0  
**日期**: 2026-05-07  
**状态**: 开发中

---

## 项目简介

这是一个面向个人投资者的量化交易系统，遵循严格的风控原则，追求长期、稳定、可监控的交易方法。

### 核心原则

1. 不承诺收益
2. 不使用杠杆
3. 不使用融资融券
4. 不做高风险衍生品
5. 不重仓单一标的
6. 不频繁交易
7. 所有交易可记录、可解释、可复盘

## 核心模块

### 风控模块 (RiskManager)

严格控制所有交易行为：

- 单笔最大风险：0.5%
- 单一标的最大仓位：10%
- 每日最大亏损：1%
- 总最大回撤：5%
- 连续亏损5次后暂停交易

### 策略模块

- **BaseStrategy**: 基础策略类
- **DualMAStrategy**: 双均线策略
- **DualMAWithStopLoss**: 双均线+止损策略

### 日志模块

完整记录所有交易行为：

- 交易日志
- 风控日志
- 系统日志
- 信号日志

## 风险参数配置

可以在 `config/__init__.py` 中修改风险参数：

```python
RISK_PARAMS = {
    '单笔最大风险比例': 0.005,    # 0.5%
    '单一标的最大仓位': 0.10,     # 10%
    '每日最大亏损': 0.01,         # 1%
    '总最大回撤': 0.05,           # 5%
    '最大连续亏损次数': 5,
    '滑点比例': 0.0005,
}
```
